# Triagem de Atendimento Inteligente com IA

Aplicação web desenvolvida em Python para análise automatizada de sentimento e extração de intenção de mensagens de clientes.

## Tecnologias Utilizadas
- **Python 3.11+**
- **Streamlit** (Interface Web)
- **Groq API** (Llama 3 / GPT-OSS)


## 🚀 Como Executar

1. Instale as dependências:
```bash
pip install -r requirements.txt
```
2. Execute a aplicação:
```bash
streamlit run interface.py
```
